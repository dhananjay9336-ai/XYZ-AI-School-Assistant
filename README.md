# 🤖 XYZ AI – Human-Like AI School Assistant

## 📌 Project Overview

XYZ AI is a standalone Applied AI School Assistant designed to interact with Students, Parents, Teachers, and School Management/Principal through Chat and Voice.

The system understands natural-language requests, identifies the user's role, detects intent, validates permissions, communicates with mock APIs, performs authorized actions, maintains conversation context, and responds naturally.

---

## 🎯 Objective

The main objective of XYZ AI is to provide a human-like AI assistant for school-related queries and actions.

The assistant supports:

- Students
- Parents
- Teachers
- Principal / School Management

---

## ✨ Key Features

- 💬 Chat-based AI interaction
- 🎤 Speech-to-Text
- 🔊 Text-to-Speech
- 🤖 AI Avatar
- 👥 Role-based assistance
- 🔐 Role-based permissions
- 📊 Attendance management
- 🚨 Teacher / Management escalation
